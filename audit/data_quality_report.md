# Data quality and independent numerical verification
Ten primary V8 Parquet surfaces were fully profiled for schema, null counts, row counts and selected natural keys. Every selected natural key has zero duplicates. Raw OHLC and all OHLC-bearing profiled panels have zero nonfinite/nonpositive or high/low ordering failures. `data_inventory.csv` and `data_schema.csv` preserve exact file hashes and field-level missingness.

Raw recovery contains 604,422 rows and 257 securities (1985-01-03 through 2026-07-01 across all recovered history). This does not define the forecasting sample. Daily all-arm membership has 897,141 rows; membership intervals have 3,060 security-interval rows spanning 94 distinct intervals; feature panel 819,427 rows; observations 820,557 rows; fold calendar 239 rows including invalid candidates; predictions 1,139,196 collapsed and 5,695,980 seed-level rows. Invalid folds and nullable metadata are retained. The original validator independently checked unique prediction keys and all five seed identities.

All 1,139,196 collapsed predictions satisfy training-end < prediction-date, label-maturity-cutoff < prediction-date, and prediction-date < target-date, with finite probabilities in [0,1] and five seeds per collapsed key. Exactly 343,792 current/PIT matched pairs have identical target keys/classes. These checks verify stored chronology, not the historical truth of every source announcement.

Independent formulas recomputed Brier score, log loss and prediction coverage for all 39,588 date groups, 336 interval groups, 60 market groups and 12 macro groups. All comparisons match within 1e-12 (maximum observed error 5.56e-16). Full-support primary bootstrap uses the original scientific engine on independently recalculated date differences; its 76 scope/block/model rows match all stored estimates, intervals and p-values within 1e-12, including unavailable-scope nulls.

The bounded training replay covers the first valid fold in each of the five markets, three arms, four models and five seeds: 300 model/baseline executions and 190,800 seed-level predictions, all numerically exact (max absolute difference 0). This does not constitute every-fold retraining. Missing Malaysian 5014 prices, absent anchor PDF, source-tier and historical-test gaps remain in `docs/LIMITATIONS.md`.
